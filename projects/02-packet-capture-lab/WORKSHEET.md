# Capture worksheet

Fill this after a capture on a network you own.

1. What interface did you capture?
2. How many packets did you keep?
3. Copy one DNS query name.
4. Copy the address from the DNS answer.
5. Find the three handshake packets to port 443 and write their flag letters (SYN, SYN-ACK, ACK).
6. Did any packet leave the lab network? If yes, stop and fix the virtual machine adapter.
