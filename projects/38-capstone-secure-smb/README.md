# 38 — Capstone: secure a small company

## What this is

Eight items that pull earlier labs together: map, firewall, hardening, secure app, backup, SIEM, incident response, and policies. `checklist.py` prints them. `CAPSTONE_REPORT.md` is the write-up.

## Why it matters

A hiring manager wants one story, not 52 folders. This is that story.

## How to run

```bash
python3 projects/38-capstone-secure-smb/checklist.py
```

## Portfolio deliverable

The filled capstone report, two pages at most.

## Exercise

Tick all eight checklist items with a project number next to each. Write the capstone report in two pages.
