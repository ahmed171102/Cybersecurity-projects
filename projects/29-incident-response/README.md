# 29 — Incident response

## What this is

A six-step playbook, a ransomware tabletop that is discussion only, and `timeline_builder.py` with five timestamped events.

## Why it matters

Incidents fail when people wipe the machine first. The order is contain, keep evidence, then recover.

## How to run

```bash
python3 projects/29-incident-response/timeline_builder.py
```

Read `PLAYBOOK.md` and answer `TABLETOP.md` on paper.

## Portfolio deliverable

The timeline plus your five tabletop answers.
