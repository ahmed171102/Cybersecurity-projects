# Ransomware tabletop

This is a discussion exercise. Do not build ransomware. Do not run encryptors against a real share.

Scenario: Monday 08:10, the lab file server shows a note that files were encrypted overnight. Backups from Sunday 18:00 were tested last month. The lab is isolated from your home network.

Discuss, in order:

1. Who decides to disconnect the file server?
2. Which logs do you keep before anyone rebuilds the VM?
3. Do you restore Sunday's backup immediately, or only after you know the Sunday copy is clean?
4. What do you tell the people waiting on the files?
5. Which single control would have made this smaller? (MFA on the admin path, or an alert on mass file renames.)

Write the answers in five lines. That is the deliverable.
