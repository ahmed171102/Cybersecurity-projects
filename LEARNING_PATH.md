# 12-week learning path

One project is enough for a sitting. Run it, change one thing, and write three sentences about what changed.

Forgetting a lecture after graduation is normal. Rebuilding the small project is how the idea comes back. The longer version of that idea is `ZERO_TO_HERO.md`.

## Weeks 1–4 — networks (projects 01–06)

| Week | Project | Done when |
| --- | --- | --- |
| 1 | `01-network-map` | You can point at trusted, IoT, and lab zones in the diagram |
| 1 | `02-packet-capture-lab` | You can tell a DNS query from a TCP handshake |
| 2 | `03-tcp-chat` | Two clients on `127.0.0.1:9000` exchange a line |
| 2 | `04-dns-resolver` | You looked up A and MX records for a name you are allowed to query |
| 3 | `05-subnet-calculator` | You can explain `/24` with the binary flag turned on |
| 4 | `06-port-scanner` | You scanned `127.0.0.1` and saw the tool refuse `8.8.8.8` |

## Weeks 5–8 — data security (projects 07–12, 24, 25)

| Week | Project | Done when |
